把本机的 5050 端口暴露到公网

在你本机跑下面这条命令，把 5050 换成你要暴露的端口，任何人就能通过分配的公网域名访问它。

# Linux / macOS tunmap-client --server http://你的服务器地址 \ --key <部署时设置的密钥> \ --port 5050
安卓手机直接安装下方 APK，填 server / key / port 点启动即可。
